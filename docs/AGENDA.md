# Agenda del hackathon

Resumen de `Agenda minuto a minuto — Hackathon Connect atVentures.pdf`.

| Hora | Actividad | Nota para el equipo |
| --- | --- | --- |
| 8:00–9:00 | Registro y desayuno | Check-in, Wi-Fi e instalación. |
| 9:00–9:10 | Bienvenida y arranque | Inicio oficial. |
| 9:10–11:15 | Sprint 1: problema → solución | Definir usuario, problema, propuesta de valor y empezar a construir. |
| 11:15–11:30 | Checkpoint 1 | Validar problema, usuario y solución con mentores. |
| 11:30–13:00 | Sprint 2: construcción | Prototipo e integraciones. |
| 13:00–13:45 | Almuerzo + build | La competencia sigue activa. |
| 13:45–14:45 | Sprint 3: producto + demo | Completar el flujo principal y hacerlo demostrable. |
| 14:45–15:00 | Checkpoint 2 | Revisar si funciona, se entiende y qué falta cerrar. |
| 15:00–15:45 | Sprint final | Ajustes y preparación del pitch. |
| **15:45** | **Cierre definitivo de entregas** | **Se congela el proyecto; no se permiten más cambios al producto.** |
| 15:45–16:30 | Evaluación del jurado | Selección de 3–4 equipos para el escenario. |
| 16:30–16:40 | Deliberación final | Puntajes, empates y premios. |
| 16:40–16:45 | Traslado al escenario | Finalistas, jurado y organización. |
| 16:45–16:50 | Apertura | Contexto breve. |
| 16:50–17:06 | Pitches de finalistas | 3–4 equipos, 3 minutos por pitch y transición. |
| 17:06–17:15 | Deliberación | Confirmación del resultado final. |
| 17:15–17:25 | Premiación | Anuncio y entrega de premios. |
| 17:25–17:30 | Foto y cierre | Agradecimientos y cierre. |

El horario y el cierre de entregas son los indicados en la agenda fuente; confirma con la organización si comunica cambios.
