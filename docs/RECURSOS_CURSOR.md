# Recursos de Cursor

La carpeta compartida incluye `Links para Cursor.pdf`, con enlaces individuales de referido y datos de contacto de varios equipos.

Por privacidad y para evitar publicar códigos de referido en el repositorio, este resumen no copia correos ni enlaces individuales. Si el equipo necesita su enlace, consúltalo directamente en el PDF compartido. No uses ni compartas enlaces de otros equipos.

La guía del evento permite declarar las herramientas utilizadas; recuerda mencionar Cursor y cualquier otra herramienta de IA o asistencia en el proyecto, según corresponda.

**Fuente:** `Links para Cursor.pdf`.
