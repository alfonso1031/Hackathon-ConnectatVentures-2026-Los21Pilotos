# Problema: quiebres de stock y ventas que se pierden

## Definición

El problema que proponemos resolver es que un cliente puede llegar a una sucursal y no encontrar el producto que necesita, mientras otras sucursales podrían tener unidades disponibles o excedentes. Si la reposición tarda, el cliente puede esperar, buscar el producto en otra farmacia o posponer la compra.

Esta formulación es una **hipótesis de producto por validar** con Farmaenlace; las fuentes del reto disponibles no cuantifican los quiebres de stock ni confirman que sean la causa principal de pérdida de clientes.

## Ejemplo ilustrativo

Don José, personaje ficticio, camina hasta su farmacia habitual para comprar un medicamento de uso frecuente. El producto se agotó y la reposición tardará varios días. Don José se va sin comprar y busca otra opción. El ejemplo ilustra una experiencia posible; no corresponde a una entrevista ni a un caso real.

## Personas afectadas

- **Cliente:** no encuentra el producto cuando lo necesita y debe buscar otra opción.
- **Planificador de abastecimiento:** debe decidir qué reponer o trasladar y cuándo hacerlo.
- **Sucursal:** puede perder una venta aunque exista inventario disponible en otra ubicación.

## Consecuencias que queremos medir

- Demanda que no se pudo atender por falta de inventario.
- Valor de productos que podrían caducar sin venderse.
- Costo y tiempo de traslados urgentes o mal dirigidos.

No afirmamos que el resultado sea “cero ventas perdidas” ni que se pierda la lealtad de cada cliente afectado. Esos efectos requieren datos y validación.
